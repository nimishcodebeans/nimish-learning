# Set up

Each page covers one setup task. In order of importance:

| Page | What you set up | Required? |
| --- | --- | --- |
| [Enable the app embed](enable-app-embed.md) | Switch the cart widget on in your theme | Yes |
| [Choose a widget template](widget-templates.md) | How the widget looks | Recommended |
| [Widget visibility](widget-visibility.md) | Who sees the widget and on which pages | Recommended |
| [Popup and support form](popup-and-support-form.md) | The form shoppers fill in, and an optional popup | Optional |
| [Email notifications](email-notifications.md) | Alerts to you and the shopper when a ticket arrives | Recommended |
| [Cart ID format](cart-id-format.md) | Text IDs or simple numbers | Optional |
| [Theme compatibility](theme-compatibility.md) | Only if the widget does not appear in the right place | If needed |

The storefront tracking pixel needs no setup. It is installed with the app.
