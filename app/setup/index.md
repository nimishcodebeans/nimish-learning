---
title: "Set up"
description: One task per page. Do these once, when you first install.
---

Each page covers one setup task. In order of importance:

| Page | What you set up | Required? |
| --- | --- | --- |
| [Enable the app embed](/app/setup/enable-app-embed) | Switch the cart widget on in your theme | Yes |
| [Choose a widget template](/app/setup/widget-templates) | How the widget looks | Recommended |
| [Widget visibility](/app/setup/widget-visibility) | Who sees the widget and on which pages | Recommended |
| [Popup and support form](/app/setup/popup-and-support-form) | The form shoppers fill in, and an optional popup | Optional |
| [Email notifications](/app/setup/email-notifications) | Alerts to you and the shopper when a ticket arrives | Recommended |
| [Cart ID format](/app/setup/cart-id-format) | Text IDs or simple numbers | Optional |
| [Theme compatibility](/app/setup/theme-compatibility) | Only if the widget does not appear in the right place | If needed |

The storefront tracking pixel needs no setup. It is installed with the app.
