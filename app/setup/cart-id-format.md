---
title: "Cart ID format"
description: Show Cart IDs as text IDs or as simple sequential numbers.
---

**Settings → General settings → Cart ID Display → Cart ID format.**

| Format | Looks like | Good for |
| --- | --- | --- |
| **Text ID** (default) | `v_yna3sj0b2` | Stable and unique from the first page view |
| **Cart Number** | `#1`, `#2`, `#3` … | Easy for shoppers to read out on the phone or type into a message |

The same value is used everywhere: on the storefront widget, in the Dashboard, in emails and in
search. You can search the Dashboard by either form.

## Switching to Cart Number

The first time you choose **Cart Number** and save, existing carts are numbered in the order they
were created, starting from `#1`. New carts continue the sequence.

A brand-new cart gets its number a moment after the shopper adds their first product. Until then,
the widget stays hidden for that cart so a shopper never sees a blank or changing number.

You can switch back to Text ID at any time. Numbers already assigned are kept.
